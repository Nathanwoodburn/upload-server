Quick CLI Setup Linux / macOS / WSL

Install the shell function in your ~/.bashrc or ~/.zshrc:

curl -sL {{ base_url }}/bashrc >> ~/.bashrc && source ~/.bashrc

Then upload anytime from your terminal:

upload report.pdf 7d

Or upload using plain curl:

curl -F "file=@report.pdf" {{ base_url }}/
